Developers

API documentation

Generate speech and clone voices from your own app. All endpoints are REST over HTTPS and return JSON.

Base URL

API access is included in the Pro and Scale plans. Create keys in Dashboard → API keys.

Authentication

Send your secret key in the x-api-key header. Keys start with vs_. Keep keys on your server — never put them in browser or mobile code.

x-api-key: vs_your_api_key

Rate limits

50 requests per minute per key (sliding window). Over the limit you get 429 RATE_LIMITED with a Retry-After header in seconds.

Credits

Usage is metered in characters: one character of input text = one credit. Cloning is free. Every success response includes a credits object. If a request costs more than your balance it fails with 402 before any audio is generated.

GET/v1/voices

Returns your cloned voices plus library voices you can use.

{
  "success": true,
  "data": [
    { "voice_id": "v_8hK2…", "name": "Morgan", "gender": "Female", "language": "en", "owner": "you" }
  ]
}

POST/v1/voice-clone

multipart/form-data

FieldTypeNotes
audiofile · requiredWAV or MP3, max 25 MB. Clean 10–30s recording works best.
namestring · required2–80 characters.
genderstringMale, Female, Neutral, Unspecified (default).
languagestringISO 639-1 code, e.g. en, ur, ar. Default en.
{
  "success": true,
  "message": "Your voice has been cloned successfully.",
  "data": { "voiceId": "v_8hK2…", "name": "Morgan", "language": "en", "gender": "Female", "createdAt": "2026-10-09T09:20:44.120Z" },
  "credits": { "cost": 0, "used": 0, "remaining": 1000000, "total": 1000000 }
}

You may only clone voices you own or have the speaker’s written permission to use.

POST/v1/text-to-speech

application/json

FieldTypeNotes
textstring · requiredUp to 50,000 characters. Long input is generated in parallel and stitched into one file.
voice_idstring · requiredFrom /v1/voices or /v1/voice-clone.
speednumber0.5 – 2.0, default 1.
titlestringOptional label shown in your dashboard history.
{
  "success": true,
  "message": "Your audio has been generated successfully.",
  "data": { "audio_url": "/v1/audio/g_x7…", "id": "g_x7…", "voice_id": "v_8hK2…", "format": "wav", "characters": 44, "speed": 1 },
  "credits": { "cost": 44, "used": 44, "remaining": 999956, "total": 1000000 }
}

audio_url is a WAV file, loudness-normalised. Append ?dl=1 to force a download.

GET/v1/credits

Returns your current plan and character balance.

Errors

Always branch on success. Failures return {"success": false, "error": {"code", "message", "fields?"}}.
